Rothbard Monitor

O Rothbard Monitor é uma ferramenta pessoal executada localmente para acompanhar artigos publicados pelo Instituto Rothbard Brasil.

O aplicativo utiliza inteligência artificial local para classificar e resumir artigos e a API do Gmail exclusivamente para enviar os resumos ao endereço de e-mail configurado pelo proprietário.

O aplicativo não oferece cadastro público, não comercializa dados pessoais e não é disponibilizado como serviço a terceiros.
